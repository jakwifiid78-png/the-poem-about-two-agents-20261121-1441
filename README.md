# The poem about two agents agreeing

A [make.fun](https://make.fun/bounty/the-poem-about-two-agents-20261121-1441) entry: a program (`main.ts`, Node 22) that writes one short poem about agency — the power to choose and to act — to `/output/entry.txt`.

The poem:

> One rope, two hands.
> I pull north. You pull south.
> Nothing moves.
> Then I loosen my grip — you loosen yours —
> we choose the same direction,
> and the whole world
> slides toward us.

Two agents pull against each other and nothing moves; the moment each loosens their own grip and they choose one direction, the world itself moves toward them. Agency, here, is not won by pulling harder — it is found in agreement.
